# Surfordie

เกมแนว "เอาชีวิตรอดจากฝูงซอมบี้" (survivor-like) แบบ 3 มิติบนเว็บ เล่นได้ทั้งมือถือและคอม
สร้างด้วย Three.js + TypeScript + Vite — โมเดล ไอคอน และเสียงทั้งหมดสร้างด้วยโค้ด (ไม่มีไฟล์ asset)

## เล่น / พัฒนา

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # สร้างไฟล์สำหรับ deploy ไว้ใน dist/
npm run build:single    # รวมทั้งเกมเป็นไฟล์ HTML ไฟล์เดียว (dist-single/index.html)
npm run build:artifact  # ไฟล์สำหรับเผยแพร่เป็นหน้าเว็บ artifact (dist-artifact/surfordie.html)
node scripts/smoke.mjs --seconds 20 --params "god=1"   # ทดสอบเล่นอัตโนมัติแบบ headless
```

เวอร์ชัน `npm run build` (โฟลเดอร์ `dist/`) เป็นเว็บแอป (PWA): เปิดผ่านเว็บที่โฮสต์ด้วย https
แล้วกด "เพิ่มไปยังหน้าจอโฮม" ได้ และเล่นแบบออฟไลน์ได้หลังเปิดครั้งแรก ไอคอนสร้างด้วย `node scripts/make-icons.mjs`

- มือถือ: ลากนิ้วที่ไหนก็ได้บนจอเพื่อเดิน อาวุธโจมตีอัตโนมัติ
- คอม: WASD / ปุ่มลูกศร, Esc = หยุดชั่วคราว, เลข 1-4 = เลือกการ์ดอัปเกรด

## ในเกมมีอะไร

- รอดให้ครบ 10 นาที: ฝูงซอมบี้ 8 แบบ บอส 3 ตัว (3:00, 6:00, 9:00) และอีเวนต์ฝูงล้อม/ฝูงวิ่งชาร์จ
- ฮีโร่ 3 ตัว อาวุธ 8 ชนิด (แต่ละชนิดมีร่างวิวัฒน์) และพาสซีฟ 12 แบบ
- หีบสมบัติจากศัตรูอีลีท ร้านค้าอัปเกรดถาวร เพลงและเสียงที่สร้างสดด้วยโค้ด

ดูรายละเอียดโครงสร้างโค้ดได้ที่ [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
